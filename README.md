## 🌐 Sobre o projeto

A **Nididas Store** é um projeto de desenvolvimento web criado com o objetivo de explorar conceitos de HTML, CSS e JavaScript na construção de uma experiência de e-commerce interativa.

A proposta é apresentar produtos de maneira moderna e envolvente, utilizando um carrossel dinâmico, efeitos visuais, animações de entrada e saída e uma identidade visual inspirada no universo tecnológico.

Mais do que uma vitrine de produtos, o projeto representa uma oportunidade de colocar em prática conceitos de desenvolvimento front-end, manipulação do DOM e construção de interfaces.

## ✨ Funcionalidades

- 🎠 **Carrossel interativo:** navegação entre diferentes produtos.
- ➡️ **Navegação dinâmica:** controles para avançar e retroceder entre os produtos.
- ⏱️ **Transição automática:** alternância automática dos produtos.
- 🎬 **Animações personalizadas:** efeitos de entrada e saída com CSS.
- 🎯 **Indicadores dinâmicos:** identificação do produto atualmente selecionado.
- 💡 **Identidade visual:** fundo tecnológico, iluminação e elementos decorativos.
- 🖱️ **Interatividade:** manipulação de elementos HTML utilizando JavaScript.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação e organização da interface |
| CSS3 | Estilização, efeitos visuais e animações |
| JavaScript | Lógica do carrossel e manipulação do DOM |
| Google Fonts | Tipografia e identidade visual |

## 🎨 Identidade visual

O projeto utiliza uma estética tecnológica, com predominância de tons escuros e detalhes em azul e ciano.

**Características visuais:**
- Fundo escuro com gradientes.
- Iluminação radial para destacar os produtos.
- Tipografia moderna com destaque para os títulos.
- Elementos geométricos decorativos.
- Botões com gradientes e efeitos visuais.
- Animações suaves para melhorar a experiência de navegação.

## 🚀 Como executar o projeto

Você pode executar o projeto localmente seguindo estes passos:

**2. Entre na pasta do projeto**

**3. Abra o projeto no VS Code**


**4. Execute a aplicação**

## 🧠 Aprendizados e desafios

Durante o desenvolvimento da Nididas Store, foram explorados conceitos importantes do desenvolvimento front-end, especialmente:

- Estruturação semântica com HTML5.
- Organização e reutilização de seletores CSS.
- Posicionamento e alinhamento de elementos.
- Utilização de `@keyframes` e `transition`.
- Manipulação de classes com `classList`.
- Seleção de elementos com `querySelector` e `getElementById`.
- Controle de eventos com `addEventListener`.
- Implementação de lógica de navegação com JavaScript.
- Controle de índices e atualização dinâmica de conteúdo.
- Sincronização de animações e transições.

Um dos principais desafios foi desenvolver um carrossel funcional, garantindo que as imagens, os textos e os indicadores acompanhassem corretamente a navegação, sem comprometer a experiência visual.
